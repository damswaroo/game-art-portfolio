# Game Gameplay & Trailer Videos (YouTube Embed)

모든 게임 프로젝트의 **GAMEPLAY / TRAILER** 섹션은 **YouTube 영상 URL 임베드 방식**으로 동작합니다.

- 웹 UI에서 프로젝트별로 YouTube 일반 링크(`youtube.com/watch?v=...`) 또는 단축 링크(`youtu.be/...`)를 등록·수정·삭제할 수 있습니다.
- 코드 레벨에서 기본 YouTube URL을 고정 등록하려면 `src/data/projectVideosData.ts` 또는 `src/data/portfolioData.ts`의 해당 프로젝트 `video.youtubeUrl` 필드에 입력하세요.
